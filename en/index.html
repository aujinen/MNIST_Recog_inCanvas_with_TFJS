[Detailed Usage Instructions] (Click this section to expand details)
[Note] Operation is only guaranteed on laptops with specifications equal to or higher than those specified by the Faculty of Dentistry.
Approximately 520MB (10 epochs) to 3.1GB (100 epochs) of memory is required for JavaScript VM operation.
It will not work on mobile devices such as iPhones. (As of 2025/10/22)
The status display window on the right side can be opened and closed with the [@] key.
You can switch between maximum and minimum screen display with the [Space] key.
=== Execution Procedure ===
● You can set the number of epochs in the range of 1 to 100.
After setting the number of epochs, click the [Run Training] button.
The training progress will be displayed on the right side.
After training is complete, draw any character in the handwriting input area.
Clicking the [Predict] button will display the recognition result.
Clicking the [Clear] button will clear the drawing area.
● To save the trained model...
　⇒ Click the [Save Model] button.
　　You will need to download two files, so
　　please allow such alerts that appear in your browser.
　　The file names are "my-mnist-model_###.json" and "my-mnist-model_###.weights.bin".
　　It will contain the number of epochs as ###.
　　*The model files are common, but due to the specifications,
　　 they are saved with different names that include the number of epochs.
●To load a saved model...
　⇒ Select the model file in JSON format and the parameter file in BIN format,
　　then click the [Load Model] button.
　　As an example, you can also load models and parameters
　　that have been trained for the corresponding epoch number in folders from '1' to '100'.
　　*The model files are exactly the same except for the part where the parameter file name is specified.
